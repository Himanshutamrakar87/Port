# Himanshu Tamrakar Portfolio

Portfolio website for Himanshu Tamrakar — AI Product Designer & MERN Stack Developer.

"Think. Design. Build. With AI."

## Overview

This project is a personal portfolio built with React and Vite, with an Express backend and Google AI integration. It showcases work, skills, and professional experience in a modern and responsive design.

## Tech Stack

- React 19
- Vite
- Express
- Tailwind CSS
- Google GenAI
- Node.js

## Features

- Responsive portfolio layout
- Modern UI with dynamic sections
- Fast frontend using Vite
- Backend API support
- AI-powered functionality via Google GenAI
- Deployment-ready configuration

## Project Structure

- `src/` — frontend React source
- `public/` — static assets
- `server/` — backend server code
- `api/` — API-related logic
- `index.html` — app entry HTML
- `server.js` — server entry file
- `vite.config.js` — Vite configuration
- `package.json` — project scripts and dependencies

## Prerequisites

Before running the project, make sure you have:

- Node.js (v18 or later)
- npm or yarn
- A valid Google AI API key if using AI features
